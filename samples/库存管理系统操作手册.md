# 库存管理系统操作手册（节选）

## 1. 登录与权限

仓管员使用工号登录。角色决定能看到哪些仓库。没有权限时不要反复点击菜单，先找主管开通「收货」「拣货」「盘点」中的一项。

必填：工号、密码、仓库编码。

## 2. 收货入库

主路径：到货登记 → 对照采购订单 → 质检 → 上架。

主键字段：ASN 号、采购订单号、物料编码、实收数量、货位。

异常：

- 实收大于订单：走超收审批，不能直接改账
- 质检不合格：入待处理库，禁止上到良品货位
- 找不到订单：先核对供应商送货单，再联系采购

## 3. 拣货出库

主路径：波次生成 → 分配库存 → 拣货 → 复核 → 发运。

系统会区分账面库存、可用库存、预留库存。可用为 0 时不要手工改数字。

异常：

- 货位无货：做移位或报缺，回退波次
- 部分缺货：允许部分发货，剩余数量保持预留或释放需主管确认
- 反审核：必须先作废拣货任务并释放预留

## 4. 盘点

循环盘点优先覆盖 A 类动销品。盘盈盘亏都要写原因码。

禁止：先改系统再盘点、跳过复盘直接过账。
